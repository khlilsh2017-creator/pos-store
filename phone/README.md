# تطبيق الهاتف

الصفحة الأساسية لتطبيق إنشاء طلبات الإنترنت على الجوال هي `add_order_ph.html` داخل هذا المجلد. تم ضبط الاعتمادات المحلية بمسارات `../`، وأضيف `manifest.json` مستقل بنطاق `/phone/` حتى يمكن تثبيت الواجهة كتطبيق منفصل عن نظام POS الرئيسي.

يمكن فتح التطبيق مباشرة عبر:

`/phone/add_order_ph.html`

ويظل الرابط القديم `/add_order_ph.html` يعمل كتحويل توافق إلى المسار الجديد.

## إدارة الطلبات من الجوال

تمت إضافة `orders.html` كواجهة مستقلة لإدارة طلبات الإنترنت، مصممة أولًا للشاشات الصغيرة. تعرض الطلبات كبطاقات بدل الجداول، وتوفر البحث برقم الطلب أو الهاتف أو اسم العميل، والتصفية بالحالة والمندوب، والتصفح بين الصفحات، وعرض تفاصيل العميل والتوصيل والبنود والملاحظات والخصومات.

تدعم الشاشة الإجراءات المسموحة حسب صلاحيات حساب POS: تعديل الطلب، إسناد المندوب، تحديث الحالة، إلغاء الطلب، وطباعة فاتورة طلب الإنترنت. تعتمد جميع العمليات على `pos_token` ولا تقرأ `driverToken` أو `driverId`.

تحتوي الصفحة على نموذج تسجيل دخول احتياطي خاص بها يظهر تلقائيًا عند عدم وجود جلسة POS أو انتهاء صلاحيتها. بعد نجاح الدخول تحفظ الصفحة `pos_token` و`pos_user` في التخزين المحلي المشترك مع POS، ثم تعيد تحميل الطلبات وفق الصلاحيات التي أعادها Worker.

## صفحة الدخول المركزية

أصبحت `phone/index.html` صفحة الدخول المنفصلة والمشتركة للتطبيقين. بعد تسجيل الدخول يمكن اختيار `add_order_ph.html` لإنشاء الطلب أو `orders.html` لإدارة الطلبات. عند فتح أي صفحة مباشرة دون جلسة POS يتم التحويل تلقائيًا إلى `index.html` مع تحديد الصفحة المطلوبة للعودة إليها بعد الدخول.
